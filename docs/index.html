NBA Analytics Pipeline

Anthony Mirete, cybersecurity student at SUNY Plattsburgh

An automated Python system that collects NBA stats, prices from 100+ sportsbooks and the league's official injury reports every day, predicts player stats with machine learning, and grades every prediction against how the market closed.

View the code on GitHub Read the security design

How it works

Small scheduled jobs on a Mac collect data from three public sources, a model turns it into predictions, and everything is graded automatically once games finish.

Collect

Every afternoon the pipeline downloads new box scores and every sportsbook's player props and game lines. A second job saves the final lines 10 to 20 minutes before each tip-off.

Predict

Each player's stat is projected by averaging a rate-based formula with a gradient-boosted model, adjusted for injured teammates, then compared with Pinnacle, the sharpest book.

Grade

After each game, every prediction is checked against the real box score and the closing market, so the system is judged on results, not impressions.

The machine-learning model

One gradient-boosted regressor (scikit-learn) per stat learns from three seasons of box scores, using only what was known before each game: recent minutes and stats, rest, home or away, opponent defense, and how much of the team's usual production was missing because players sat out.

To test it honestly, it was trained on the 2024-25 season only, then asked to predict every game of 2025-26 it had never seen.

Security design

The code is public, so anything secret or personal has to stay out of it by design, not by remembering to delete it.

  • Secrets live outside the codeAPI keys are read at runtime from a local .env file (permissions 600) or environment variables, through one small module.
  • Nothing sensitive is committable.gitignore excludes the keys, every data file, logs and personal betting records. The first commit was scanned for key-like strings before publishing.
  • Alert channel treated as a credentialThe phone-notification channel works like a bearer token: it is randomly generated on the device, stored with the other secrets and never printed by the tools.
  • Untrusted input is handled as untrustedDownloaded reports are checked for a valid PDF signature before parsing, and names from external data are HTML-escaped before the app displays them.
  • Bad data is filtered, not trustedExchange quotes that don't form a real two-way market, mislabeled first-half lines and unmatched names are detected and dropped automatically.
  • Polite to the services it usesEvery request has a timeout, NBA.com downloads retry with growing back-off and pause between calls, and each run reports the remaining API quota.

What broke, and how it was fixed

Most of the work was making messy real-world data trustworthy.

Fake two-way prices

An exchange quoted both sides of a prop as favorites (Over -330 and Under -225), which looked like a coin flip after removing the margin. Lines whose sides add up to more than a 15% margin are now dropped: 232 on opening night.

Silent upstream change

The league moved its injury report to a new 15-minute file naming scheme, and the open-source parser kept requesting the old names. The fetcher now builds the new URLs itself and reports the last error instead of failing quietly.

Schema drift

Each model version added columns, and appending to the history file mixed row widths until grading crashed. Rows are now aligned by column name whenever the layout changes.

Model bias

On opening night the first model leaned Over on 76% of props because it trusted last season's playoff minutes. Restricting to regular-season data and averaging in the ML model brought it to an even split.

Live results

Tracking started on October 20, 2026. Every pick is scored by closing line value: the closing market's fair probability minus the probability implied by the price taken. It is the fastest reliable test of whether a model has an edge, settling in a few hundred picks instead of thousands.

Results will be published here once there are enough graded picks to mean something.
